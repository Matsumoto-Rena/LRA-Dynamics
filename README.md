# プログラム説明
- LraDynamicsBoardLarge-sineWave350Hz
  - 堺が作成した基板で350zの正弦波をDAC出力するためのコードです． 
- M5StickCPLUS2-use2MD_DS4
  - 2つのLRAを鉛直/水平方向に対象振動させることで前後移動可能.
  - DS4を接続し遠隔制御可能
  - M5StickCPLUS2にはバッテリも搭載されており完全独立に駆動可能
  - 動画は[こちら](https://robohanactive.slack.com/archives/C08RF0U7A49/p1759132342633789)
- M5StackCore-MoveLRA_2D
  - M5StackCoreと優先で接続された4つのLRAが固定されたものをボタン操作で動かせます
  - 動画は[こちら](https://robohanactive.slack.com/archives/C08RF0U7A49/p1758611733020689?thread_ts=1758611265.424999&cid=C08RF0U7A49)
